# Zone Stretch

**English** · [Bahasa Indonesia](#bahasa-indonesia)

Stretch or shrink only the part of an object between two limit planes; works inside nested groups and components. Free SketchUp extension by Andi Dewanto — Windows & macOS, SketchUp 2021+. Version **1.4.0**.

- Website: https://andidewanto.github.io/zone-stretch/
- Download: [`downloads/ad_zone_stretch-1.4.0.rbz`](downloads/ad_zone_stretch-1.4.0.rbz)
- Tutorial (English / Indonesian): https://andidewanto.github.io/zone-stretch/tutorial.html
- Install: SketchUp › **Extensions › Extension Manager › Install Extension…** › choose the `.rbz`.
- More extensions: https://andidewanto.github.io/sketchup-extensions/

Contact & bug reports: andidewanto@gmail.com
